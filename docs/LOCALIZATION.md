# 中英本地化验证

公开 0.9.3 包尚不含本轮本地化。源码通过 key/格式检查、编译和非 GUI Bundle 查找验证不等于全流程 UI 已验收。按维护者要求，本轮保留当前播放状态、跳过实机录制和视觉截图，没有生成虚构的英文截图。

```sh
python3 scripts/check_localization.py
./build.sh
```

主应用和内嵌 WallFlowPlayer 都复制 zh-Hans.lproj、en.lproj，开发语言为 zh-Hans。系统语言为英文时匹配英文，不支持的语言回退中文。用户自带的壁纸标题、显示器名称和错误中的文件名不会被翻译。

后续在可停止旧后台播放器的测试会话中验证（先保留当前配置）：

```sh
open -n "$PWD/dist/Wallnamic.app" --args -AppleLanguages '(en)'
# 完全退出该测试会话，再测试中文；不要让两个管理端争用同一个后台播放器。
open -n "$PWD/dist/Wallnamic.app" --args -AppleLanguages '(zh-Hans)'
```

逐项检查：主窗口/空状态、导入与失败提示、显示器分配、设置和播放策略、创意工坊、菜单栏、弹窗、通知与辅助功能标签；检查英文长文本截断、中文原文、参数显示与取消/退出流程。先确认截图只含原创合成壁纸，隐藏用户库、路径和账号；未经实机验收不要对外宣称完整英文体验。

## 实机 UI 验收记录（0.9.4）

2026-10-22 夜间，本机以 `/Applications/Wallnamic.app`（build 23，ad-hoc 签名）分别用 `-AppleLanguages '(en)'` 与 `'(zh-Hans)'` 完成一轮界面验收；两种语言之间完全退出主应用与后台播放器后再启动，避免争用。验收手段为辅助功能树与 Vision OCR，截图仅用于核对，未对外发布，且未保留含账号/路径的图。

已覆盖：

- 主窗口：品牌名、侧栏（我的壁纸、搜索、筛选、排序、创意工坊、设置）、详情区（应用到 / 画面显示 / 声音、视频参数、显示器列表）。
- 设置 sheet：完成；壁纸库与自动播放；性能与电源（桌面完全被遮挡时暂停、电池供电时暂停、低电量模式时暂停）；停止壁纸并完全退出。
- 创意工坊 sheet：下载账号、已登录账号、登录下载账号、选择工具…、浏览工坊…、读取 Steam 订阅…、其他来源、完成。
- 菜单栏状态菜单：管理壁纸…/恢复播放（暂停态）/退出；应用菜单退出与编辑菜单。
- 辅助功能标签：搜索我的壁纸、壁纸排序、重命名壁纸、收藏壁纸、查看壁纸详情。
- 用户壁纸标题、Steam 账号名与显示器硬件名保持原文；内建显示器名走系统本地化（内建视网膜显示器 / Built-in Retina Display）。
- 英文与中文词条表 314 键一致，抽样与界面实测文案一致；视频参数格式为 `W × H · 秒/sec`。

未覆盖（仍不宣称完整英文体验的边界）：

- 空库空状态、导入失败/转码失败弹窗、系统通知、分组重命名等低频弹窗。
- 英文长文案在极端窄窗下的截断，以及全部显示器/电源组合。
- 未做录屏与对外发布截图。
