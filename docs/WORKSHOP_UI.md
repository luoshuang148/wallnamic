# 创意工坊界面改版（2026-10-29）

目标是让用户凭画面挑选壁纸，明确区分发现、订阅同步与下载配置。旧界面以账号表单和文字清单为主，图片内容缺位。

| --- | --- | --- |

这是对交互模式的归纳，界面使用项目既有 SwiftUI 和青绿色强调色实现。

## 应用到项目

- 左侧放发现壁纸、我的订阅、同步订阅、链接下载和其他来源，底部放账号配置入口。
- 我的订阅使用 Steam API 的真实预览图片；缺图时显示占位图标。
- 名称和编号搜索与全部、待下载、已导入筛选放在网格上方。
- 卡片显示标题、体积或已导入状态、详情入口和选择标记。
- 已导入作品保留正常预览亮度，点击不会重复加入下载选择。
- 底部持续显示选择总量、状态和批量下载操作；失败详情可展开。
- 账号、登录和工具路径配置放入弹窗。

现有公开工坊浏览器继续使用官方页面；本次没有实现独立的工坊搜索后端或改变作品权限。

## 页面内自动同步

进入工坊即后台同步，点击同步按钮可再次刷新。同步目标由当前下载账号解析出的 SteamID 确定；隐藏的 WebKit 读取器复用应用内网页会话，逐页验证账号身份、分页数量和作品信息。登录不匹配或访问失败时在当前页面显示错误，不打开订阅页面，也不将失败当作空列表成功。

切换账号会取消旧请求并清除上一账号的候选列表；同账号刷新失败保留上一次完整结果。关闭页面会取消进行中的同步。同步只读取订阅，不下载作品。

反馈保留在侧栏“同步订阅”按钮的图标位置：处理中循环旋转双箭头，成功后原地绘出对勾，停留约 1.3 秒后恢复双箭头；不显示中央浮层。开启减少动态效果时保留静态图标与状态文字。

后台读取器阻止图片、媒体和字体请求，列表 DOM 结构完整即可读取并停止其余加载，不再等待整页资源完成或每页额外停顿 0.5 秒。读取前校验 DOM 的账号、来源和页码，防止误读上一页。默认同步器复用 WebKit 实例，手动刷新无需重建读取器。Steam 首个网络请求的耗时仍可能波动。
